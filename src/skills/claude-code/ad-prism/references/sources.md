# Methodological sources

Use the smallest source set that supports the recommendation. Cite the source
beside the claim it supports and explain its contribution in plain language.
These sources establish methods, not project-specific sample sizes, margins, or
decision thresholds.

## Decision and evidence chains

- NASA, [Goal/Question/Metric
  paradigm](https://ntrs.nasa.gov/api/citations/19920010178/downloads/19920010178.pdf)
  — derives answerable questions and measures from an explicit goal.
- ETS, [Evidence-Centered
  Design](https://www.ets.org/Media/Research/pdf/TC-10-07.pdf) — connects claims
  to the evidence and tasks capable of producing it.

## Evaluation construction

- OpenAI, [Evaluation best
  practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices)
  — supports task-specific evaluations, representative distributions, edge
  cases, human calibration, and continuous evaluation.
- Anthropic, [Demystifying evals for AI
  agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
  — distinguishes tasks, trials, graders, traces, outcomes, and the evaluation
  harness.

## Assurance and fit for purpose

- UK Government, [The Aqua Book](https://www.gov.uk/guidance/the-aqua-book) —
  supports proportionate analytical assurance, verification, and explicit
  quality responsibilities.
- UK Government, [The Magenta
  Book](https://www.gov.uk/government/publications/the-magenta-book/magenta-book-central-government-guidance-on-evaluation-html)
  — supports decision-focused evaluation, theory-led design, and
  fit-for-purpose interpretation.

## Transfer rule

Do not transfer sample sizes, thresholds, margins, rubrics, or claimed power
from a cited evaluation without a justified mapping to the current population,
decision, design, variance or event-rate assumptions, and error choices.
