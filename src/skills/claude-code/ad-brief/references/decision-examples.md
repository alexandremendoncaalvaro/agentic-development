# Owner-decision examples

These examples define decision shape, not reusable facts or exact wording. Select
the matching mode and preserve the evidence in the current fact packet.

## Settled path

Use when evidence, a binding decision, convergent research, or simplicity makes
one path clearly superior. State the chosen path and why in the relevant brief
fields. Do not turn the rejected path into an option.

```markdown
- **Your attention:** No decision needed; work continues with the focused test and
  then the full local gate.
```

## Owner judgment

Use only when value, taste, risk tolerance, or another genuine owner judgment can
change the outcome. Keep the setup declarative. Put the single owner decision in
`Your attention`; do not ask it once in the setup and again at the end.

```markdown
- **Your attention:** Which first-use default should we ship?
  - **A — Compact (Recommended):** lower initial burden; the detailed guide remains
    available and the choice is reversible.
  - **B — Detailed:** stronger guided onboarding; every first use becomes longer,
    and the choice is reversible.
```

Include only viable competitors. If evidence makes one option clearly superior,
use **Settled path** instead.

## Completed decision

Use when the work was already decided or completed and the owner needs to audit
it. The brief states the decision, rationale, evidence and its limit, concrete
next action, and absence of an owner decision.

```markdown
- **Recent result:** The causal fix passed the repeated reproduction and the full
  gate; the unrelated workaround was discarded because it never reproduced the
  failure.
- **Confidence:** The conclusion is limited to the repeated path and full local
  gate that were actually exercised.
- **Next:** Run the independent review, then continue through the normal delivery
  flow if it finds no real issue.
- **Your attention:** No decision needed; work continues with independent review.
```

Assess the meaning of the rendered brief. Do not use punctuation counts, copied
phrases, or the presence of these headings as substitutes for the decision rule.
